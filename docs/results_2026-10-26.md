# Experiment record — 2026-10-26

**Status:** observations reported from a successful local run on Apple Silicon. The evaluated application and training scripts were still local at the time this record was committed; reproduce after source code is pushed. No model artifact is attached to this repository.

## Research question

How does a small LoRA adaptation of an existing binary sentiment classifier change predictive performance and individual errors on Yelp customer reviews?

## Model and data

- Baseline checkpoint: `distilbert/distilbert-base-uncased-finetuned-sst-2-english` (a checkpoint already trained for SST-2 sentiment classification).
- Adaptation: PEFT LoRA for sequence classification, with `q_lin` and `v_lin` targets and trainable `pre_classifier` and `classifier` modules.
- LoRA settings: rank `8`, alpha `16`, dropout `0.1`.
- Dataset: `fancyzhx/yelp_polarity`, using its published train/test separation; Yelp labels `0 = NEGATIVE`, `1 = POSITIVE`.
- Development: shuffled training split (`seed=42`), 512 training records and 128 validation records.
- Training: 1 epoch, initial learning rate `2e-4` (with scheduler), per-device training batch size `4`, input truncated/padded to a maximum of 128 tokens.
- Trainable parameters: 739,586 out of 67,694,596 (approximately 1.09%).
- Recorded training loss: 0.3813; validation loss: 0.4625. These figures are **not** accuracy measurements.
- Comparison: 200 examples from the Yelp test split selected by `shuffle(seed=42).select(range(100, 300))`; the two models received the **same** reviews, capped at 128 tokens.
- Earlier exploratory baseline: 100 different shuffled Yelp test reviews, 85% accuracy. **Do not compare this number with the fine-tuned result**, because the sample differs.

## Same-review comparison (200 examples)

| Measurement | Pretrained baseline | LoRA-adapted classifier |
| --- | ---: | ---: |
| Accuracy | 87.5% | 90.0% |
| Precision for negative sentiment | 85.58% | 90.72% |
| Recall for negative sentiment | 89.90% | 88.89% |
| Average inference time, CPU, ms/review | 24.40 | 25.13 |

Confusion matrices use rows = actual labels and columns = predicted labels, in the order `NEGATIVE, POSITIVE`:

**Pretrained baseline**

```text
[[89, 10],
 [15, 86]]
```

**LoRA-adapted**

```text

 [ 9, 92]]
```

On this evaluation set, the adapted model fixed 6 baseline errors and introduced 1 new error, yielding a net improvement of 5 correct predictions (2.5 percentage points).

## Interpretation

- Overall accuracy and precision for the negative class improved on this particular 200-review evaluation.
- Recall for negative reviews fell slightly: missed negative cases rose from 10 to 11, while false alarms fell from 15 to 9.
- This does **not** establish that LoRA will consistently improve sentiment classification on other datasets, review types, or sample draws.
- Both models saw the same truncated text; longer review content may be excluded from inference.
- The 200-review set is small, the adaptation used only 512 training examples, and the displayed precision/recall focus on one designated class.
- The single-run latency figures include batch inference but exclude loading the models; they are preliminary rather than a statistically reliable speed comparison.
- Labelled Yelp Polarity reviews are not a gold standard for every ambiguous, mixed-aspect customer complaint.
- The comparison set was selected separately from the first 100 exploratory examples. Avoid using these 200 evaluation outcomes to keep adjusting training settings without documenting test-set reuse.

## Sunboard retrieval and generation case study

A **historical sample of 19 reviews** for a product previously sold by the developer was extracted from a May 2026 review log. It is not the total number of product reviews and should not be described that way.

- The private local CSV is intentionally under `data/raw/` and excluded from Git.
- Sentence embeddings use `sentence-transformers/all-MiniLM-L6-v2` and top-3 cosine similarity search; a sample instability-related query returned SB02 (0.411), SB07 (0.393), SB17 (0.387).
- The highest-ranked result discussed lack of backrest flexing, whereas another directly described wobbling. Semantic similarity does **not** guarantee agreement, useful grounding, or reliable support for a generated answer.
- `google/flan-t5-small` produced unusable text in the first experiment; `Qwen/Qwen2.5-0.5B-Instruct` subsequently produced a coherent but generic draft. Its dependence on retrieved reviews was not empirically established.
- Generated replies are for **human review**, not autonomous customer communication.
